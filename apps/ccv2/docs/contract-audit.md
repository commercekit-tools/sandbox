# SAP Management API 2.0.12 contract audit

This audit compares the independently authored sandbox contract and its HTTP
behavior with SAP Commerce Cloud Cloud Portal Management API **2.0.12**. The
authoritative source is SAP's [Cloud Portal API documentation](https://help.sap.com/docs/SAP_COMMERCE_CLOUD_PUBLIC_CLOUD/0fa6bcf4736c46f78c248512391eb467/66abfe678b55457fab235ce8039dda71.html?locale=en-US).
The SAP-authored OpenAPI document was inspected during the audit and was not
copied into this repository.

The review checked method, complete path, operation ID, path and query
parameters, request media type and shape, response status, response media type
and shape, error media type, pagination, and authentication for every operation.
`scripts/validate-openapi.js` now enforces that inventory against the maintained
contract. Worker-runtime tests validate representative real request and response
bodies by operation family.

No known critical or high-severity request/response incompatibility remains in
the build and deployment workflows. The sandbox does not claim that synthetic
side effects are equivalent to SAP infrastructure behavior.

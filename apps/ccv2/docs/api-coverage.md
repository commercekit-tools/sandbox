# SAP Cloud Portal Management API coverage

This matrix is an independently authored inventory of the operations exposed by
SAP Commerce Cloud Management API version **2.0.12**. The authoritative source
is the [SAP Cloud Portal API documentation](https://help.sap.com/docs/SAP_COMMERCE_CLOUD_PUBLIC_CLOUD/0fa6bcf4736c46f78c248512391eb467/66abfe678b55457fab235ce8039dda71.html?locale=en-US).
It records compatibility work without redistributing SAP's authored OpenAPI
document.

All vendor-compatible operations require an RS256 bearer token in
`x-approuter-authorization`. Collection reads use the documented `$top`, `$skip`,
`$orderby`, and `$count` conventions where the source operation exposes them;
`$top` is capped at 100. Errors use `application/problem+json` with at least
`title` and `detail`. A status of **implemented** means the operation has a real,
state-aware handler and test coverage rather than a catch-all response.

## Scope decisions

- SCIM is not one of the ten families exposed by Management API 2.0.12. No
  unverified SCIM path is registered or advertised. A later independently
  versioned extension can add SCIM when an authoritative contract is selected.
- The sandbox adds deterministic 429 and 500 fault responses to exercise client
  resilience. These are marked as simulation behavior where an operation's SAP
  page does not explicitly enumerate them.
- CommerceKit run and scenario operations live only under `/__mock/*` and are
  documented separately from the compatibility surface.
